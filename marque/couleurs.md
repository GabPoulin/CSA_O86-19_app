# Couleurs et polices

Remplis les codes hexadécimaux (ex. `#324D1E`). Laisse vide ce que tu n'as pas.

## Couleurs de la marque

Source : `palette.png` (fournie par l'utilisateur).

| Rôle | Nom | Code hex | Utilisation prévue dans l'application |
|---|---|---|---|
| Principale | Vert forêt | `#233614` | en-têtes, barre latérale, fond du logo blanc |
| Accent | Orange brûlé | `#9E5A00` | boutons, liens, éléments actifs, ligne orange du logo |
| Texte | Charbon | `#333333` | texte principal, logo sur fond clair |
| Neutre | Gris | `#8F8F8F` | bordures, éléments désactivés, texte secondaire en grand format seulement |
| Fond secondaire | Gris pâle | `#EEEEEE` | cartes, champs de saisie, sections |
| Fond clair | Sable | `#F4F1EA` | fond des pages |

### Lisibilité (contraste, norme d'accessibilité WCAG)

Un texte normal demande un contraste d'au moins **4.5**.

| Combinaison | Contraste | Texte normal |
|---|---|---|
| Charbon sur sable | 11.20 | ✅ |
| Vert forêt sur sable (ou sable sur vert forêt) | 11.57 | ✅ |
| Blanc sur vert forêt | 13.05 | ✅ |
| Charbon sur gris pâle | 10.89 | ✅ |
| Blanc sur orange brûlé (boutons) | 5.36 | ✅ |
| Orange brûlé sur sable (liens) | 4.75 | ✅ |
| Gris sur sable | 2.87 | ⚠️ seulement pour les bordures ou les grands textes |
| Orange brûlé sur vert forêt | 2.43 | ❌ à éviter pour du texte (correct comme élément décoratif, comme dans le logo) |
