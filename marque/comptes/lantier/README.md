# Groupe Lantier

Selon la charte graphique de Groupe Lantier (2021) :

- `logo.svg` : logo horizontal en couleurs (p. 4, version à prioriser), utilisé dans l'en-tête de la note ;
- `logo_renverse.svg` : logo horizontal renversé, pour les fonds foncés (p. 4) ;
- `logo_vertical.svg` et `logo_vertical_renverse.svg` : logo vertical, pour les mises en page centrées (p. 2) ;
- `symbole.svg` : symbole seul ;
- `couleurs.toml` : vert foncé `#273c3c` et sarcelle `#47aeaa` (p. 6) ;
- `polices.toml` : Rift Bold pour les titres en majuscules, DIN 2014 Regular pour le texte (p. 7). Les
  fichiers `.otf` vont dans `polices/`, qui n'est pas dans git (polices sous licence, dépôt public).
