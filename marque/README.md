# Image de marque : Le Repère Ingénierie

Ce dossier contient l'image de marque utilisée par l'application (logos, couleurs, polices).

## Où déposer quoi

| Dossier ou fichier | Quoi déposer |
|---|---|
| `logos/` | Les logos. **SVG de préférence** (net à toutes les tailles), sinon PNG haute résolution (au moins 1000 px de large, fond transparent). |
| `couleurs.md` | Les couleurs, avec leurs codes hexadécimaux (ex. `#324D1E`). Le fichier est déjà prêt à remplir. |
| `polices/` | Les fichiers de polices (`.woff2`, `.ttf` ou `.otf`), ou seulement leur nom dans `couleurs.md` si ce sont des polices Google Fonts. |

### Logos utiles (si tu les as)

- logo complet **Le Repère Ingénierie** (couleur) ;
- version **monochrome** ou **blanche** (pour un fond foncé) ;
- **symbole seul** (sans texte), pour l'icône de l'application sur l'iPhone et l'onglet du navigateur ;
- logo **Datum**, le jour où il existe.

Nomme les fichiers simplement, sans accents ni espaces, par exemple :
`le-repere-ingenierie-couleur.svg`, `le-repere-ingenierie-blanc.svg`, `le-repere-symbole.svg`.
